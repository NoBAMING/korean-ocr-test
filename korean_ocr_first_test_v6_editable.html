형광펜 독서 연구소 · OCR 테스트 v6

책 사진에서 글자를 인식하고, 틀린 글자를 직접 고쳐 확정하는 단계야.

① 테스트할 사진

✂️ 사진 위에서 마우스나 손가락으로 드래그해 본문 영역을 선택해 줘. 선택하지 않으면 사진 전체를 인식해.

선택한 영역만 잘라서 OCR해. 다른 사진으로 바꿔도 다시 선택할 수 있어.

② 한국어 인식 결과

준비 완료. 아래 버튼을 눌러 한국어 인식을 시작해 줘.
실험 설정 (필요할 때만 열기)

사진 형태는 실험 설정을 안내하기 위한 선택이야. 휘어진 사진도 우선 곡면 보정 0으로 인식해 보고, 필요할 때만 보정을 올려 보자.

글줄이 실제로 휘어 보일 때만 조금씩 조절해. 이 기능은 자동 펴기가 아니라 수동으로 이미지 조각을 이동시키는 실험 기능이야.
인식 결과가 나오면 틀린 글자를 직접 고칠 수 있어.

인식 결과를 확인하고 틀린 글자나 띄어쓰기를 고친 뒤 ‘수정 완료’를 눌러 줘.

처음 실행 시 한국어 데이터(약 수 MB)를 한 번 다운로드해. 이후에는 브라우저 캐시를 사용할 수 있어.

진단 정보

아직 다운로드 검사를 실행하지 않았어.

이 테스트는 Tesseract.js 5와 한국어 전용 학습 데이터를 사용해. 공식 문서의 언어 데이터 경로 규칙에 맞춰 직접 주소를 검사하도록 만들었어.
